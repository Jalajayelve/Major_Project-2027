# Agent 2 quality figures

The report figures are generated by
`notebooks/generate_agent2_quality_figures.py` from
`data/processed/agent2/oof_predictions.csv`.

- [Reliability diagram](../reports/agent2-quality/agent2_reliability_diagram.png)
- [Confusion matrix at cutoff 0.42](../reports/agent2-quality/agent2_confusion_matrix_threshold_042.png)

Both figures use the `with_profile_strength` predictions from the five-fold
`GroupKFold(applicant_id)` run. The reliability diagram uses ten uniform
probability bins. The confusion matrix uses the requested 0.42 cutoff.
These are pooled grouped out-of-fold diagnostics on unverified CSV labels, not
an independent external test-set result or evidence of real-world calibration.

To regenerate them from the repository root:

```powershell
python notebooks/generate_agent2_quality_figures.py
```
