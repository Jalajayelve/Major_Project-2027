# Project Flow

## Development flow
1. Set up backend environment
2. Run the FastAPI server on port 5000
3. Verify health endpoint at /health
4. Test prediction endpoints with sample payloads
5. Run Streamlit frontend
6. Submit student profile from the UI
7. Send request to backend prediction route
8. Fetch recommendation list from matching endpoint
9. Review results and iterate on logic
