# StudyPath — Reflex counselling prototype

Python-first study-abroad counselling flow built with Reflex. The browser UI is React generated by Reflex and the server API is FastAPI under the hood.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies: `C:/Users/DELL/AppData/Local/Python/pythoncore-3.14-64/python.exe -m pip install -r requirements.txt`
3. Start the app: `C:/Users/DELL/AppData/Local/Python/pythoncore-3.14-64/python.exe -m reflex run`
4. Open `http://localhost:3001/`. StudyPath uses dedicated frontend and backend ports so it does not collide with another Reflex project using the defaults.

To force specific ports when needed, set `STUDYPATH_FRONTEND_PORT` and `STUDYPATH_BACKEND_PORT` before starting the app.

## Demo journey

1. Create an account or sign in from the authorization page.
2. Complete the student profile and submit it to run the counselling pipeline.
3. Review the calculated tier and university matches.
4. Choose a next-step card to ask the appropriate specialised counselling agent.

The recommendation engine is intentionally deterministic demo logic. Replace the functions in `study_path/engine.py` with calls to a LangGraph/FastAPI gateway when the production agents are available; the UI state contracts are already separated from the interface.
